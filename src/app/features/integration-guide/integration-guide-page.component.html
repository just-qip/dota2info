Integration Guide

Embeddable Dota2DB web components — item, hero and ability icons with rich tooltips. Works on any site: plain HTML, React, Vue, Svelte, WordPress.

1. Quick start

ℹ️ How it works

The script ships a fully self-contained Angular application that boots the first time a widget appears on the page. JSON datasets are fetched directly from dota2db.com — your site does not need to host anything.

2. Href auto-embed

The most convenient way to render a widget — just write a plain link to the corresponding page on dota2db.com. The script automatically detects such links in your markup (and in anything added later) and replaces their content with the matching widget.

Link to page

Inside prose

Because only the content is swapped and the anchor itself is preserved, auto-embed works well inside regular paragraphs — no manual tags needed: 

{{ snippetHrefMixed }}
ℹ️ When does it run?

The embedder runs once on page load and continues watching the DOM via MutationObserver. Links that are added later — after an AJAX request, a framework render, or a lazy chunk — are picked up too.

⚠️ All matching links are rewritten

Auto-embed is opt-out by host: every <a> whose href points to dota2db.com with a recognised path is replaced. If you want to keep a link as plain text, don't use <a> for it, or render the widget explicitly via <dota-*-icon>.

4. Sizing

Icons respect the CSS variable --dota-icon-size. Set it via inline style or CSS — every widget inside the container will pick it up. 

{{ snippetSizeInline }}

Defaults: 72px for items, 88px for heroes and abilities.

7. Data & CORS

All datasets (items.json, heroes.json, abilities.json, hero_lore.json, patchnotes.json) are served from our domain with permissive CORS headers. You do not need to proxy or cache anything.
